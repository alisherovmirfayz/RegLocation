# RegLocation — Проект №2: Teacher + Director

Мобильный сайт учителя и кабинет директора (React + Vite + Tailwind + Motion). Небольшой веб-сервер (`server/server.mjs`) раздаёт сайт и проксирует `/api` и `/socket.io` на backend проекта №1 — поэтому сайт работает на собственном домене без проблем с cookie и CORS.

Полная инструкция — в `README.md` в корне репозитория.

## Адреса

| Путь | Назначение |
|---|---|
| `/teacher` | вход учителя → кабинет, «Я в школе», расписание, профиль |
| `/director/register` | первичная регистрация директора (только один раз, с подтверждением email) |
| `/director/login` | вход директора |
| `/director` | панель: главная, учителя, расписания, посещаемость, управление монитором, редактор школы, этажи и кабинеты, доступ к монитору, история, настройки |

Старые адреса с `.html` перенаправляются на новые.

## Команды

```bash
npm install
npm run dev                      # http://localhost:5174 (прокси к backend на :8080)
npm run build                    # сборка в dist/
API_UPSTREAM=https://monitor.example.com npm start   # production-сервер
npm test                         # тесты веб-сервера
```

Переменные окружения — в `.env.example`.
